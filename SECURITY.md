# Security policy / 安全策略

`0.1.x` is a beta line. Security fixes target the newest beta only.

Please use GitHub private vulnerability reporting after the repository enables it. Do not publish an issue containing an exploit, a private scene, a local authentication token, or a full private file path. Include the plugin and OBS versions, operating system, file format and size, minimal reproduction steps, impact, and whether a synthetic fixture can reproduce the problem.

`0.1.x` 为 Beta 版本，仅为最新 Beta 提供安全修复。仓库启用后，请使用 GitHub 私密漏洞报告，不要在公开 Issue 中提交利用代码、私有场景、本地认证令牌或完整私有路径。请说明插件与 OBS 版本、系统、文件格式和大小、最小复现步骤、影响，以及能否使用合成测试文件复现。
