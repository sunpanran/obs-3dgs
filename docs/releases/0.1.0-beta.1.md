# obs-3dgs 0.1.0-beta.1

An OBS source for local Gaussian-splat livestream backgrounds, with a native control Dock and Chinese/English UI. Windows and macOS builds are maintained and distributed together in this repository.

用于将本地 3D 高斯场景作为直播背景的 OBS 来源插件，提供原生实时控制 Dock 与中英文界面。Windows 和 macOS 版本在本仓库统一构建和发布。

## Included / 功能

- PLY, Compressed PLY, SPZ, and SOG. SPLAT, KSPLAT, ZIP, and RAD are experimental.
- Scene transforms, 16–200 mm camera controls, interaction, display/quality presets, saved views and OBS hotkeys.
- Six compact settings pages, independent source state, and live safety locking.
- Failed replacements retain the last valid scene; file access uses authenticated loopback routes.
- 即时场景变换、摄影相机、鼠标交互、显示与画质调整、镜头预设、热键及直播防误触。
- 文件加载失败时保留有效场景；六类属性页与 Dock 共享状态。

## Packages / 文件

- `obs-3dgs-0.1.0-beta.1-windows-x64.zip`
- `obs-3dgs-0.1.0-beta.1-macos-universal.zip`
- Each ZIP has an adjacent SHA-256 file and contains an SBOM, third-party licenses and bilingual documentation.
- 每个 ZIP 都提供 SHA-256，包内包含 SBOM、第三方许可证和双语说明；示例场景不打进插件包。

Install by copying the plugin folder/bundle. [English instructions](../install.md) · [中文安装说明](../install.zh-CN.md).
No installer is required. macOS uses ad-hoc signing without Developer ID notarization.

## Acceptance status / 验收状态

This release remains a **draft** until the required hardware and frontend checks are complete.

- Windows and macOS Universal pass compilation, automated tests, packaging and SHA-256 checks in the same CI workflow.
- Windows: seven-format load/error recovery, HTTP boundaries, lifecycle, 100 native duplicate/private-state checks and both wide/close 30-minute recording gates have evidence in `docs/benchmarks/`. Close view measured 60.0024 FPS, 16.7 ms frame P95 and zero OBS render skips.
- macOS still requires Apple Silicon hardware acceptance; M1 Balanced 1080p30 requires ≥29 FPS and frame P95 ≤36 ms.
- Remaining frontend checks: OBS Paste (Duplicate) including private UI state, property Cancel, complete Dock/interaction synchronization, Missing Files dialog and physical hotkey binding.
- Valid RAD scene rendering is unverified. RTX 4060 performance is a Stable gate; it does not block the first Beta.
- 当前保持草稿：Apple M1 性能及剩余 OBS 前端人工验收尚未完成，不能将 CI 构建成功等同于真机验收。

See [testing](../testing.md) / [测试说明](../testing.zh-CN.md) for current evidence and exact boundaries.
