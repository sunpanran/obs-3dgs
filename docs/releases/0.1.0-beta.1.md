# obs-3dgs 0.1.0-beta.1

An OBS source for local Gaussian-splat livestream backgrounds, with a live control Dock. Windows and macOS builds are maintained and distributed together in this repository.

用于将本地 3D 高斯场景作为直播背景的 OBS 来源插件，提供实时控制 Dock。Windows 和 macOS 版本在本仓库统一构建和发布。

**macOS has not been tested in OBS on a physical Mac. macOS CI builds and automated tests do not verify real-machine installation, plugin loading, rendering or performance.**

**macOS 尚未在真实 Mac 的 OBS 中验证安装、插件加载、渲染及性能。CI 构建和自动测试通过不能替代实机验证。**

## Included / 功能

- PLY, Compressed PLY, SPZ, and SOG. SPLAT, KSPLAT, ZIP, and RAD are experimental.
- Scene transforms, 16–200 mm camera controls, interaction, display/quality presets, saved views and OBS hotkeys.
- Six compact settings pages, independent source state, and live safety locking.
- Camera / Scene / Presets Dock tabs, with grouped and nested-group source selection.
- Failed replacements retain the last valid scene; file access uses authenticated loopback routes.
- 即时场景变换、摄影相机、鼠标交互、显示与画质调整、镜头预设、热键及直播防误触。
- 文件加载失败时保留有效场景；六类属性页与 Dock 共享状态。
- 实时控制分为相机、场景和预设页签，支持群组与嵌套群组中的来源。

## Acceptance status / 验收状态

This is a **beta prerelease**. Windows manual acceptance is complete, including user retests of preset hotkeys, missing-file recovery, grouped-source selection and the updated Dock layout. macOS hardware validation remains pending.

- Windows and macOS Universal pass compilation, automated tests, packaging and SHA-256 checks in the same CI workflow.
- Windows 11 / OBS 32.2.2 / RTX 4090: eight-format/variant load/error recovery, HTTP boundaries, lifecycle, 100 native duplicate/private-state checks and both wide/close 30-minute recording gates have evidence in `docs/benchmarks/`. Close view measured 60.0024 FPS, 16.7 ms frame P95 and zero OBS render skips at 1920×1080, 75% internal render scale, 1M LOD and SH2.
- macOS hardware validation remains pending. The M1 Balanced 1080p30 targets of ≥29 FPS and frame P95 ≤36 ms have not been demonstrated on a physical Mac.
- Source save/load passed 100 cycles; real CEF context loss restored the first time and reached a stable error on the next attempt without crashing OBS.
- The Missing Files Apply crash and hidden Dock contents are fixed. Explicit file recovery preserves the camera, presets and live lock. [Recovery regression](../benchmarks/2026-09-04-windows-frontend-recovery.md) · [群组及布局回归](../benchmarks/2026-09-04-dock-groups-layout.zh-CN.md).
- [Windows acceptance record](../manual-acceptance.md) · [Windows 验收记录](../manual-acceptance.zh-CN.md).
- Single-file RAD rendering and error recovery passed a minimal fixture; external multi-file chunks remain outside scope. RTX 4060 performance is a Stable gate; it does not block the first Beta.
- Windows 用户验收及反馈问题的复测已完成。本次发布为 Beta；macOS 尚未实机验证，真机测试在发布后补做。

See [testing](../testing.md) / [测试说明](../testing.zh-CN.md) for current evidence and exact boundaries.
