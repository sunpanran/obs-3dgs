# 故障排查

- **来源列表中没有插件：**核对文件夹结构和 OBS 32.0+ 版本，然后在“帮助 > 日志文件 > 查看当前日志”中搜索 `[obs-3dgs]`。
- **Browser Source 不可用：**安装与 OBS 版本匹配的浏览器来源组件。插件会显示内置错误图，不会让 OBS 崩溃。
- **场景上下颠倒：**把“坐标预设”从“自动”改为 OpenGL/Y-up、OpenCV/X-180 或 Z-up。
- **新文件加载失败：**上一张有效 GPU 场景会继续显示。重新打开来源属性可查看不包含完整路径的校验错误。
- **透明背景变黑：**在“显示”中选择“透明”，并确认后续 OBS 滤镜没有强制不透明 Alpha。
- **交互无反应：**关闭“直播防误触”，再打开“鼠标调整视角”。左键环绕、右键平移、滚轮推拉，`R` 复位。
- **性能不足：**选择“性能”或“平衡”，降低 LOD 高斯预算，并保持 OBS 的 Browser Source 硬件加速开启。

报告问题时请提供 OBS 版本、系统、GPU、格式与文件大小、质量档位、复现步骤和 OBS 日志。不要上传私有场景。诊断导出默认必须隐藏目录，只保留文件名与大小。
