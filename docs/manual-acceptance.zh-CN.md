# 交付前人工验收

自动化结果与复现命令见 [测试说明](testing.zh-CN.md)。本表保留需要实际 OBS 窗口或指定硬件的检查，未勾选项不代表已经通过。

## Windows / macOS 前端

使用专用 OBS 场景集合和公开示例。先记录 OBS、插件、系统、GPU 版本与输出分辨率。

- [ ] 在来源列表“复制 → 粘贴（副本）”，确认分类页与高级相机展开状态被复制；修改副本焦段、预设和分类，原来源不变。原生 API 的 100 次复制与私有状态隔离已自动验证，菜单点击仍需此项。
- [ ] 打开属性页，修改焦段、曝光、场景位置，然后点“取消”：图像回到原状态，最后浏览的分类保留。对应 libobs 取消调用路径已自动验证，窗口按钮与关闭确认对话框仍需此项。
- [ ] 在属性页输入 85 mm，查看 Dock；再从 Dock 输入 35 mm，查看画布和重开的属性页。在交互窗口拖动后关闭，确认取景同步且数值不跳回。
- [ ] 开启直播防误触，确认不能修改场景、相机、外观和质量，仍能浏览分类并应用已保存预设。
- [ ] 在 OBS 设置中实际绑定一个预设热键，回到主窗口触发，确认选中预设与画面同步；直播锁定时仍可切换保存的预设。
- [ ] 关闭 OBS 后移动样例，重开并通过 OBS“缺失文件”窗口定位新路径；确认恢复画面和预设。
- [ ] 将 3DGS 放在摄像头层下，检查透明背景和常用滤镜合成。

## Apple Silicon 门槛

macOS Universal 构建通过只证明编译、测试与打包；以下项目须在真实 Mac 的 OBS 中完成。

- [ ] 安装 Universal 包并确认 OBS 日志成功加载 `obs-3dgs`。
- [ ] Apple M1：1920×1080、30 FPS、75% 内部比例、1M LOD、SH2。若将目标 FPS 从平衡预设的 60 改为 30，界面会显示“自定义”，其余数值维持平衡档即可。
- [ ] 使用 `Knock Community Hall` 和固定相机，记录平均 ≥29 FPS、逐帧 P95 ≤36 ms、渲染延迟丢帧 <0.5%。保留原始帧时间、截图、设备信息与相机设置。
- [ ] 静止观察时没有持续重绘和排序；重复加载/卸载后内存不持续增长。

在已设好上述 30 FPS 参数的专用 OBS 简单输出配置中，选择可用的 macOS 录制编码器。设置本机 WebSocket 密码后可运行以下命令；脚本按实际 GPU、数值画质、逐帧数据与录制文件检查 M1 门槛，不会把 M1 Pro/Max 或软件渲染器算作基础 M1。

```text
npm run test:obs:renderer -- --duration-seconds 60 --record true --gate apple-m1 --pose docs/benchmarks/data/knock-community-hall-close-camera.json
```

RTX 4060 8 GB 同标准为 Stable 门槛；M2+ 1080p60 为目标，不阻塞首个 Beta。当前 RAD 有效样例仍缺实测，不应计为完整格式验收。
