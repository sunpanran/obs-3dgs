# 技术架构

`obs-3dgs` 明确分离 OBS 原生集成与高斯渲染。

```text
OBS 来源属性 + Qt Dock + 热键
                │
          原生状态唯一来源
                │ javascript_event / 带认证 HTTP 事件
       私有 browser_source
                │
       Three.js + Spark WebGL2
```

C++ 来源持有可持久化设置、来源 UUID、镜头预设、直播锁定策略和私有 Browser Source 生命周期。运行时端口、令牌、资源 URL、加载状态与性能指标绝不写入 OBS 场景集合。

Web 层持有 GPU 资源。新 `SplatMesh` 会先在场景外完成初始化，成功后才替换旧模型；场景变换和坐标转换位于不同节点。相机固定使用 36 mm 传感器，焦段范围 16–200 mm，FOV 只作为派生结果显示。

进程级服务器只绑定操作系统随机分配的 `127.0.0.1` 端口。资源路由只指向一个规范化普通文件，必须携带每次启动随机生成的令牌，并支持 GET、HEAD、Range 和取消。内置 Web 目录为只读内容，不包含用户文件。

渲染由失效事件驱动。加载、交互、相机变化或 Spark 排序会按所选目标帧率请求帧；画面稳定后停止持续请求帧。
