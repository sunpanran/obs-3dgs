# 安全设计

导入的场景一律视为不可信输入。在 Spark 读取之前，原生层会确认它是规范化普通文件、拒绝直接符号链接、检查支持的扩展名与格式签名、校验关键头部边界；超过 1 GiB 警告，非 RAD 文件超过 2 GiB 拒绝。

服务器绝不绑定局域网地址，也不会从 `127.0.0.1` 回退到 `0.0.0.0`。资源 URL 必须携带进程随机令牌，只映射一个准确的规范化文件，禁用缓存，并在来源换文件或销毁时失效。反向事件正文限制为 64 KiB，同时校验协议版本、来源 UUID、revision 类型、事件类型和 JSON 结构。

项目没有遥测。运行时 URL、令牌、端口和性能指标不会持久化。日志与诊断默认不得暴露所选文件的完整路径。

这些措施能缩小攻击面，但不能保证第三方解析器永远不存在缺陷。未来仓库建立安全联系人后，请先私下报告安全问题，再公开披露。
